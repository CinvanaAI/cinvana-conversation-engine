# Origin and public curation

This repository is a reviewed snapshot of the live Conversation Engine source.
The working tree's allowed implementation scope—source package, tests, docs,
metadata, and contracts—was copied without entering its private `Runtime/`
directory.

The public snapshot adds this provenance record, an explicit license status,
security guidance, and an empty runtime-boundary note. A minified Mermaid bundle
without adjacent attribution was removed; the diagram atlas uses a public CDN.
No engine behavior or private runtime state was copied or rewritten.
